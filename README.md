# NovaTech — Proyecto base HTML y CSS

Proyecto educativo de una **empresa ficticia**, pensado para practicar la estructura de una página web y su diseño visual.

## Cómo abrirlo

1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code (o cualquier editor de texto).
3. Abre `index.html` en un navegador.
4. Cambia el código y actualiza la página para ver los resultados.

## Archivos

- `index.html`: estructura y contenido.
- `styles.css`: colores, tamaños y distribución.
- `img/ilustracion.svg`: imagen de demostración.

## Primeras actividades

1. Cambia el nombre de la empresa, título y descripción.
2. Cambia los textos de los tres servicios.
3. Agrega un cuarto servicio con el mismo estilo.
4. Cambia el color principal en `styles.css`.
5. Agrega una sección nueva con una lista de cinco beneficios.
6. Comprueba que el menú lleve a las secciones correctas.
7. Guarda cada actividad en un commit de GitHub con un mensaje descriptivo.

## Reglas

- No usar información real ni confidencial de la empresa.
- El formulario es visual: **no envía ni guarda datos**.
- Cada estudiante trabaja en su propia copia del proyecto.
- Intentar explicar qué etiqueta o propiedad se cambió y por qué.
